## structuredData

<ApiEntry
  kind="function"
  name="structuredData"
  since="since 1.0.0"
  lang="ts"
  signature={`export default function structuredData(options?: StructuredDataOptions): AstroIntegration`}
  params={[
    { name: 'options', type: 'StructuredDataOptions', desc: 'See Integration options. Validated immediately; invalid options throw.' },
  ]}
>
  Registers the configuration the components read, the middleware for meta tags and graph mode,
  the Dev Toolbar panel, and the post-build JSON-LD check.
</ApiEntry>

## validateRecommended

<ApiEntry
  kind="function"
  name="validateRecommended"
  since="since 1.3.0"
  lang="ts"
  signature={`function validateRecommended(type: SchemaType, data: Record<string, unknown>): RecommendedWarning[]`}
  params={[
    { name: 'type', type: 'SchemaType', desc: 'schema.org @type name, e.g. "Organization" or "BlogPosting".' },
    { name: 'data', type: 'Record<string, unknown>', desc: 'The props or schema object to check.' },
  ]}
>
  Returns one `{ field, message }` entry per missing recommended field. The build-time warning
  uses the same declaration.
</ApiEntry>

## calculateReadingTime

<ApiEntry

  name="calculateReadingTime"
